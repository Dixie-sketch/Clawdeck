# Code of Conduct

SideCrab is a hobby project maintained by one person in spare time. The bar is simple.

**Be decent.** Ask questions plainly, answer them patiently, review code and not people. Assume
the other person is trying to help, because they almost always are.

**Not welcome here:** harassment of any kind, personal attacks, discriminatory language,
publishing someone's private information, or persistent hostility after being asked to stop.
This applies in issues, pull requests, discussions and anywhere else you are representing the
project.

**If something goes wrong,** contact the maintainer through GitHub (a private vulnerability
report on the repository's Security tab reaches them even for non-security matters, or mention
them in a discussion). Reports are read, taken seriously, and kept confidential where possible.
The maintainer may edit or remove comments, close threads, and block accounts that break these
rules, temporarily or permanently, at their discretion.

That is the whole policy.
