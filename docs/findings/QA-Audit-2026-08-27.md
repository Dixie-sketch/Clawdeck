## Verdict
The widget is injection-sound; the companion's HTTP surface had the real defects. The headline: the
localhost API grew from a read-only feed (wave 1) into a control surface that approves permissions
and injects prompts, but kept its "any local caller is trusted, no Origin check" posture. **A web
page the operator merely visited could arm panel approvals and approve a pending Bash permission.**
Closed.

## To BACKLOG (ranked, not fixed tonight)

contract drifts are CLOSED. Remaining rows below stand as written.*

  writes each hook as its own matcher), but a hole in the guard whose job is protecting operator edits.

  Cheap peek→send→drain reorder (`ContinueQueue.peek()` exists). Deferred to avoid a handler collision.

  at worst one 500 that self-heals.
